VIRA WEBSITE

Static website prepared for GitHub Pages. The app remains in development; these
files do not announce a public App Store release or an approved security product.

Files
  index.html          Vira landing page
  Support.html        Support guidance and email contact
  PrivacyPolicy.html  App privacy policy
  .nojekyll           Serve the static files without Jekyll processing

Deploy from a repository root
1. Place these files at the root of the intended GitHub repository.
2. Commit them to the branch selected for publishing.
3. In repository Settings > Pages, choose Deploy from a branch, select that
   branch and / (root), then save. Confirm the deployment succeeds.
4. Open the actual HTTPS Pages URL and verify the home, support, and privacy pages.
   Do not assume a URL before GitHub provides it. A custom domain is optional.

Keep the capitalized Support.html and PrivacyPolicy.html filenames: links are
case-sensitive. Relative links support a Pages project-site subdirectory. No
absolute site URL, custom domain, analytics, scripts, forms, fonts, external images,
API calls, or build step are configured. The files can also be opened locally.

Before store submission, review the final privacy policy against the shipped app,
its hosting and support operations, and provider practices. Use only verified public
HTTPS Support and Privacy Policy URLs in the store listing. GitHub Pages records and
retains visitor IP addresses for security, as disclosed in the policy.
